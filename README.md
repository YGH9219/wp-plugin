# Personal CTA Blocks

워드프레스 글에 `/ㅂㅌ`으로 추가할 수 있는 반응형 펄스 CTA 버튼 블록입니다.

## 다음 버전 배포

1. `personal-cta-blocks.php`와 `blocks/pulse-button/block.json`의 버전을 같은 값으로 올립니다.
2. `main`에 커밋·푸시합니다.
3. 같은 버전의 태그를 푸시합니다. 예: `git tag v0.1.3` 후 `git push origin v0.1.3`.

태그가 푸시되면 GitHub Actions가 설치 가능한 ZIP을 만들고 GitHub Release에 올립니다. 설치된 플러그인은 워드프레스 기본 업데이트 화면에서 새 버전을 감지합니다.
